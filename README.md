# FaithPay – Church Donation Dashboard

FaithPay is a simple React + Vite application for recording and managing church donations. It was built as a practice project to demonstrate React fundamentals and responsive UI development using React Bootstrap.

## Features

- Add donations
- Dashboard summary
- Recent donations table
- LocalStorage persistence
- Responsive design
- React Bootstrap UI

## Tech Stack

- React
- Vite
- React Router DOM
- React Bootstrap
- LocalStorage

## Installation

npm install

npm run dev
